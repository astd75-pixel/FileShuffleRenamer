# File Shuffle Renamer

Настольное приложение для Windows 11: случайно перемешивает файлы непосредственно в выбранной папке и предлагает новую нумерацию, сохраняя расширения.

## Сборка Windows EXE через GitHub Actions

В этой среде нельзя запустить нативную Windows-сборку. В проект уже включён автоматический workflow `.github/workflows/build-windows.yml`, который собирает настоящий автономный `FileShuffleRenamer.exe` на Windows runner GitHub Actions.

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него все файлы этого архива (включая скрытую папку `.github`).
3. Откройте вкладку **Actions** и разрешите запуск workflows, если GitHub попросит.
4. Запустите **Build Windows EXE** через **Run workflow**.
5. По завершении откройте запуск workflow и скачайте artifact **FileShuffleRenamer-Windows-x64**. Внутри будет `FileShuffleRenamer.exe`.
6. Для публикации релиза с EXE создайте и отправьте тег вида `v1.0.0`.

После сборки приложение работает без Python и интернета. Сборка x64 предназначена для Windows 11 x64.

## Локальная разработка / тесты

```powershell
py -3.12 -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt pyinstaller
python -m unittest discover -s tests -v
pyinstaller --clean --noconfirm FileShuffleRenamer.spec
```

## Безопасность

- Вложенные папки не обрабатываются.
- Содержимое файлов не читается и не меняется.
- Перед подтверждением изменения существуют только в предварительном просмотре.
- Переименование выполняется в два этапа через уникальные временные имена.
- Проверяются конфликты, недопустимые символы и права доступа.
- Журнал хранится в `.FileShuffleRenamer` внутри выбранной папки.
- Кнопка отмены восстанавливает имена по последнему журналу.

Важно: не перемещайте и не переименовывайте файлы вручную между операцией и её отменой. Если сторонняя программа заняла исходное имя, отмена будет остановлена проверкой конфликта, без перезаписи.
